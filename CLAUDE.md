# Werkafspraken voor Claude
Deze repository bevat de gebouwde website van Lionsclub De Bommelerwaard in de map `site/`.
Volg deze afspraken in elke thread.

## 1. Begin van een nieuwe thread: branch controleren
- Kijk eerst of de laatst gebruikte branch nog bestaat op GitHub. De laatst gebruikte branch staat in het projectgeheugen, of anders in de laatste thread.
- **Bestaat hij nog?** Haal dan de laatste versie op (`git fetch` en `git pull`) en werk daarop verder.
- **Bestaat hij niet meer?** Maak dan een nieuwe branch aan vanaf de nieuwste `main`.

## 2. Committen
- Commit na elke interactie met de gebruiker, en push de branch naar GitHub.
- Commit **nooit** naar `main`.

## 3. Pull requests
- Maak **nooit** zelf een PR aan. Doe dat alleen als de gebruiker erom vraagt.

## 4. De site draaien
- Run de nieuwe branch in de cloud
- Verklein de plaatsje en video alleen voor deze preview en niet committen 

## Laat zien dat je bezig bent
- Zorg dat de gebruiker altijd ziet, dat je bezig bent
